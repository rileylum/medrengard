From a ticket to a pull request

Pick a scenario and press ▶. The real controller takes the ticket through every stage of the workflow you pick. In autopilot a script plays the agents at the speed you choose. In Step through the same script waits for your Next before each action. In I play the agents you choose what the developer commits, how each check behaves and what each reviewer says.

Amber is the controller: it decides. Cyan is an agent: it only claims. Violet is you, the owner: you accept, cancel or start again. Click a stage in the diagram to see where it can go next. Click a row in the event log for its JSON, or switch the log to the lines events prints.

Things to try

Break the claim

In I play the agents, commit, then edit the reply: delete the json block, shorten the SHA, or name the base commit. The controller never takes the agent's word for it.

Spend the budget

FAIL the first standard review. A fix run starts. FAIL it again: the cycle stops and waits for you. Open a child cycle and every budget starts empty.

Interfere

While a run is going, press Owner cancels or main moves on. The agent finishes, and its result changes nothing: the cycle is already settled.

Change the workflow

Pick with a stage of its own and a PACKAGE stage runs after the reviews. Pick light and one reviewer gets three tries. The diagram, the budgets and the roles follow the workflow.

Dispute a finding

After a FAIL, the developer card has dispute instead. It keeps the commit and gives a reason. The cycle escalates: only you can weigh a dispute against a verdict.

Ship two tickets

Accept, merge, then press Next ticket. The next cycle's base is the merge commit: every run starts from the repository's current tip.

The loop never decides

run() calls develop() once, then looks at the kind of stage the cycle is in: an agent stage that commits gets fix(), one that reviews gets review(), a command stage gets verify(). It never moves a stage itself: each step records an event, and apply decides where that leaves the cycle. At a human stage, or a stage that settles the cycle, the loop returns.

If a step throws, the loop cannot tell what happened, so it does not guess. It records reject_dispatch with the message, which escalates the cycle, and you decide.

Before the developer starts, run refuses a sandbox that cannot start and a grant nobody gave: either would fail only after a paid developer run.
