The Software Factory

You write a ticket. A controller takes it through a workflow to a pull request: an agent writes the code, the controller runs the checks itself, reviewers read the result, and you decide.

This guide shows how that works, from the big ideas down to the real code. The code on these pages is read from the repository when you open them, and most demos run the factory's own modules in your browser.

The rules every workflow keeps

  1. The controller decides. Agents return claims.
  2. Every piece of evidence is bound to one commit SHA.
  3. Every loop spends a budget, and stops at the limit.
  4. Anything the controller cannot classify goes to the owner.
  5. Candidate code runs in a sandbox.
  6. Only the owner hands out a credential.
