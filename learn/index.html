The Software Factory

You write a ticket. A controller takes it to a pull request: an agent writes the code, the controller runs the checks itself, two kinds of reviewer read the result, and you decide.

This guide shows how that works, from the big ideas down to the real code. The code on these pages is read from the repository when you open them, and most demos run the factory's own modules in your browser.

The five rules

  1. Only the controller changes state. Agents return claims.
  2. Every piece of evidence is bound to one commit SHA.
  3. Two standard reviews and one adversarial review per cycle. Then it stops.
  4. Anything the controller cannot classify goes to the owner.
  5. Humans accept and merge. Nothing merges itself.
